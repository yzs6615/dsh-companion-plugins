# ChronoLife：小伴自己的生活

让小伴在没人找她的时候也在“过日子”：她有一间自己的小屋，窗台上养着一盆植物，会整理笔记、写点东西、发呆休息，也会真的去刷 B站、听歌、看番。
聊天时她记得这些事，偶尔也会主动跟你说一句。

开关：`.env` 里 `CHRONOLIFE=true`。关掉就回到原来的样子（见最后“回退”）。

---

## 一、她平时在干什么

### 1. 小屋里的日常（ChronoLife 自己算，不花模型钱）

每 30 分钟维护一次（bridge 在跑时由 bridge 做，bridge 没开时由 Windows 定时任务 `Companion-ChronoLife-Tick` 做）。

| 东西 | 怎么变 |
| --- | --- |
| 窗台的植物 | 按天长：种子 → 发芽（第 2 天）→ 幼苗（第 7 天）→ 展开新叶（第 30 天）。换阶段时记一笔 |
| 活动 | 照顾植物、整理笔记、构思写点东西、休息。每次维护有 16% 的机会开始一件；一天最多 4 件，也可能一整天什么都不做。夜里（23 点到 9 点）、你 20 分钟内找过她时不开始新活动 |
| 兴趣 | 每种活动有个权重（默认都是 1），主人可以调，权重高的更常做 |
| 心情 | 愉快、活跃、好奇三个数，6 小时左右慢慢回到平常；跟原来的心情标签接在一起。你没回她不算关系变差 |
| 状态 | 聊天中、空闲、活动中、休息、停用 |
| 停机 | 电脑关了一阵再开，只补一条“离开了 X 小时”的记录，植物按时间长到该到的阶段，不会编出这几天每天干了啥 |

### 2. 活动的具体内容（模型写）

ChronoLife 只记“浇了水”“整理了笔记”这种骨架。每次维护时，bridge 挑最近 12 小时里一件还没细节的活动（休息不算），
让模型补一两句这次具体干了啥：植物出了什么小状况（不超出它现在的阶段）、笔记里记了什么、草稿干脆写成一小段文字。
一次只补一件；模型写不成就保留原句，不反复花钱。一天最多跟活动次数一样，4 次左右，每次很短。

### 3. 自己找事做（真的去刷，算她的活动）

原来的“自己找事做”（`AUTONOMY`）照常跑：刷 B站、听歌、看番、找你可能喜欢的东西，写一段日记。
开着 ChronoLife 时，这段日记同时记进她的生活时间线（记成“真做过的事”）。她在休息或被停用时不去玩。
这部分的花费跟没开 ChronoLife 时一样（`AUTONOMY_MAX`，现在每天最多 8 次）。

## 二、聊天时她知道什么

每次回复前，提示词里带：

- **原来的状态**（没变）：现在几点、心情、精力、今天干过什么、跟你多熟、作息有没有被你带偏。
- **小屋近况**（新加的一小段）：植物到哪一步了、最近 4 件事（只有事情本身和“X 小时前”）、之前停了多久。
  还提醒她：这是自己小屋里的事，别说成在现实里出了门；你没回、很久没来，都不代表关系变差，别催、别怪你。
- **你让她记住的**：用 `/生活 记住` 记下的事，只在当时那个聊天里带（私聊的不会带进群，群里的不会带进私聊）。

不带编号、来源、可信度这类机器字段。

## 三、主动找你说话

**现在是开着的**（2026-10-27 打开）。主人私聊发 `/生活 主动 关` 可以关。

### 她会说什么

- 小屋里刚发生的、有具体内容的事：比如写了一句什么、植物换了阶段、旅行回来。
- 自己找事做时刷到觉得你会喜欢的东西。

话由模型用她自己的口气写，像随口一提，不出现“虚拟”“模拟”“系统”这类词。她觉得没什么好说的可以不说。
同一件事对同一个人只问一次要不要说。

### 什么时候会发（全部满足才发）

| 规矩 | 说明 |
| --- | --- |
| 发给谁 | 只发给 `PROACTIVE_QQ` 里、同时在私聊白名单里的人；不发群 |
| 一周最多 3 条 | 所有人加起来、滚动 7 天算 |
| 上一条要回过 | 她上一条主动消息你没回，就不再发下一条 |
| 隔 24 小时 | 同一个人两条主动消息之间至少隔一天 |
| 不在夜里 | 23 点到第二天 9 点不发（时区 Asia/Bangkok） |
| 不打断聊天 | 你 20 分钟内刚跟她聊过就不发，聊天时自然会提 |
| 有事才说 | 必须是最近两天里真记录过的事；那件事被删掉了，排着队的消息也作废 |
| 不重发 | 先排队再发；发没发成说不清时不自动重发 |

### 这些主动消息不再单独发了

开着 ChronoLife 时，下面这些原来的主动通道都交给上面这套规矩统一管，免得好几个一起找你：
早安晚安冒泡、到点回访、戳一戳、没回就追问、群里插嘴、电脑室友主动搭话、每周自动写信。
你明确让她设的提醒、你点播的东西、普通回复都照常。旅行明信片不主动寄，等你来聊天时给。

## 四、命令

私聊或群里按原来的唤醒方式发 `/生活 帮助`。

| 命令 | 谁能用 | 作用 |
| --- | --- | --- |
| `/生活 状态` | 所有人 | 现在在干嘛、植物、主动分享开没开、免打扰时段 |
| `/生活 事件` | 所有人 | 她最近的经历 |
| `/生活 记忆` | 所有人 | 当前这个聊天里记着的东西和编号 |
| `/生活 记住 内容` | 所有人 | 让她记住一件事 |
| `/生活 更正 编号 新内容`、`/生活 删除 编号` | 所有人（只能改自己这个聊天的） | 改或删一条；主人私聊还能删她的经历 |
| `/生活 主动 开` / `关` | 主人私聊 | 主动分享开关 |
| `/生活 暂停` / `恢复` | 主人私聊 | 让她休息 / 回来 |
| `/生活 停用` / `启用` | 主人私聊 | 停掉整个虚拟生活（聊天照常） |
| `/生活 兴趣 plant 2` | 主人私聊 | 调某种活动的权重（plant、notes、sketch、rest，0~10） |

主人是 `PC_OWNER`，没设就是 `PROACTIVE_QQ` 第一个，再没有就是私聊白名单第一个。

## 五、设置和存储

`.env`：`CHRONOLIFE=true`、`CHRONOLIFE_TIMEZONE=Asia/Bangkok`、`CHRONOLIFE_TICK_MINUTES=30`、`CHRONOLIFE_PROACTIVE=true`。
这几个只在第一次建库时当初始值；之后用 `/生活` 改的设置存在数据库里，重启不会被 `.env` 覆盖，改了马上生效。

数据：`data/chronolife/life.sqlite`（加 WAL 文件）；`redactions.json` 记着删掉的内容，防止旧资料再被带回来；
`last-tick.log`、`last-tick.err` 是定时任务最近一次的结果。

删除是“以后不再用”，原来的聊天记录、已经发出去的消息和备份还在；换了说法的同一件事，靠文字比对认不出来。
数据库打不开时普通聊天照常，只是不再主动分享、不带小屋近况。

## 六、维护和回退

- `node chronolife/worker.mjs --status`：看现在的状态，不发消息。
- `powershell -File chronolife/register-task.ps1`：注册 30 分钟一次的定时任务；加 `-Remove` 撤掉。电脑关机、睡眠时不跑，开机后补算。
- 回退：先停 bridge，撤掉定时任务，`.env` 里 `CHRONOLIFE=false`，原来的行为就回来了。
  要恢复原文件，只从 `backups/chronolife-20261027-024410` 拿同名文件放回去，保留 data 和新数据库；这个目录没有 git，不要 git reset。
