# 拆分清单（开发用）

内核 `packages/core/kernel/main.mjs` 里每个功能搬到哪个插件。搬法：

1. 新建（或接着写）`packages/<插件>/module.mjs`，`export default function setup(api) { ... }`，按 docs/插件接口.md。
2. 把下面列的函数、常量、它们的 `on(...)` 登记行、`setInterval`/启动日志（main 段里的）原样搬进 setup 里；
   用到的内核东西从 `api` 解构（`const { cfg, env, log, state, saveState, userState, reply, say, runAgent, ... } = api;`），
   human.mjs 的东西从 `api.human` 拿；`setInterval(f, ms)` 改成 `api.every(ms, f, 第一次ms)`；启动时跑一次的放 `api.on('startup', ...)`。
3. config.mjs 里这组的设置项挪进插件导出的 `settings(env, parseList)`，setup 里 `Object.assign(cfg, settings(env, api.parseList))`（默认值不变）；功能页的行写进导出的 `features(cfg, ctx)`。别的插件读到 `cfg.xxx` 为 undefined = 关。
4. 内核里还在用的地方改成走钩子或 `api.use('服务')`（没装就跳过/用默认）。内核里不能再出现这组的函数名。
5. 这组带的脚本、python、素材（bili/、scene/ ……）搬到 `packages/<插件>/` 下，路径改成相对插件目录（`path.dirname(fileURLToPath(import.meta.url))`）；
   test/ 里引用的路径一起改。
6. `node scripts/test-all.mjs` 全部通过才算搬完；再 `COMPANION_ONLY=` （只有本体）跑 `node test/e2e.mjs` 确认本体单独也能跑。

共用的文件：
- tts.mjs（要 ws 包）只放 speech；电台（life）、电脑喇叭（pc）要合成语音走 `api.use('voice')?.speak(text, opts)`（返回 `{ wav, seconds }`），没装 speech 就不出声。电台拼语音要的 parseWav / makeWav 是 `packages/life/wav.mjs`（跟 tts.mjs 里的一样），跟 radio.mjs 放一起。
  radio.mjs 原来从 human.mjs 拿 speakable，现在自己抄了一份（插件不 import 本体的文件）。
- stickers.mjs 只放 speech。本体 `kernel/scripts/sticker-index.mjs`（给表情库配描述，要用本体的设置调模型）抄了一份 listStickers / readIndex / writeIndex，不 import 插件。
- imagegen.mjs 小，life（礼物、明信片）和 proactive（信纸）各带一份，本体没有了。
- 挑帧拼图 frames.py：本体看发来的视频用 `kernel/media/frames.py`，life 刷 B站用 `packages/life/bili/frames.py`（一样的两份）。
  听写 asr.py：本体 `kernel/media/asr.py`，life 刷 B站 `--listen` 用自己带的 `packages/life/media/asr.py`（一样的两份）；phone 用它自己的 live/phone_live.py。
- life 带的命令行脚本（bili/bili.mjs、life/life.mjs、chronolife/worker.mjs）原来 import 本体的 config.mjs 读 .env，现在读插件里的 `env.mjs`
  （COMPANION_HOME/.env，没设 COMPANION_HOME 就当插件目录；数据目录 BRIDGE_DATA 优先，没有就是 <COMPANION_HOME>/data）。内核调模型时环境变量本来就齐。
  ChronoLife 的几项设置在 `chronolife/settings.mjs`，插件和 worker.mjs 共用；run-tick.ps1 找数据目录也先看 BRIDGE_DATA、再看 COMPANION_HOME。
- 包的依赖写在 scripts/plugins.mjs 的 `deps` 里（只有 speech 要 ws），make-entries 写进 package.json。

兼容（别人自己装的 DSH 也要能直接装）：
- 插件包不写 `engines.dsh`、不依赖 `@deepseek-ai/*`：DSH 装插件时按这两样卡版本。入口只用 `apply(ctx)` 和卸载回调（`ctx.effect` 没有就 `ctx.on('dispose')`）。
- 本体和插件之间走 `globalThis.__dshCompanion` 登记表，不用 cordis 服务。
- 只在 Windows 上能用的（PowerShell、adb.exe、QQ 音乐、桌面、喇叭）放 pc / phone 插件里，别的系统上 setup 里直接说一声就返回，别让内核挂掉。
- `node:sqlite`（ChronoLife）只在 life 插件里用、用到时再 import：老的 Node 22 没有它，静态 import 会让整个内核起不来。
- 跑 python 用 `env.PYTHON`（内核按系统默认成 python / python3）；模型、素材只认本地，绝不自己去网上下。
- 路径一律从插件自己的目录算（`import.meta.url`），不许出现本机的绝对路径（老机器人的目录、用户目录这种）和本机才有的文件（老的交接文档、启动器脚本）。

本体留下：连 QQ、白名单、人设、短期记忆、熟悉度、连发合并、打字节奏、手滑、超时、引用、撤回、看懂视频文件、附和点表情、/提醒 /喂鱼 /心情 /status /new /help、守护。
