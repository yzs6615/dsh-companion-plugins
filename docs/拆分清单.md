# 拆分清单（开发用）

内核 `packages/core/kernel/main.mjs` 里每个功能搬到哪个插件。搬法：

1. 新建（或接着写）`packages/<插件>/module.mjs`，`export default function setup(api) { ... }`，按 docs/插件接口.md。
2. 把下面列的函数、常量、它们的 `on(...)` 登记行、`setInterval`/启动日志（main 段里的）原样搬进 setup 里；
   用到的内核东西从 `api` 解构（`const { cfg, env, log, state, saveState, userState, reply, say, runAgent, ... } = api;`），
   human.mjs 的东西从 `api.human` 拿；`setInterval(f, ms)` 改成 `api.every(ms, f, 第一次ms)`；启动时跑一次的放 `api.on('startup', ...)`。
3. config.mjs 里这组的设置项挪进插件：`Object.assign(cfg, { ... })`（默认值不变）。别的插件读到 `cfg.xxx` 为 undefined = 关。
4. 内核里还在用的地方改成走钩子或 `api.use('服务')`（没装就跳过/用默认）。内核里不能再出现这组的函数名。
5. 这组带的脚本、python、素材（bili/、scene/ ……）搬到 `packages/<插件>/` 下，路径改成相对插件目录（`path.dirname(fileURLToPath(import.meta.url))`）；
   test/ 里引用的路径一起改。
6. `node scripts/test-all.mjs` 全部通过才算搬完；再 `COMPANION_ONLY=` （只有本体）跑 `node test/e2e.mjs` 确认本体单独也能跑。

共用的文件：
- tts.mjs（要 ws 包）只放 speech；电台（life）、电脑喇叭（pc）要合成语音走 `api.use('voice')?.speak(text, opts)`（返回 `{ wav, seconds }`），没装 speech 就不出声。
- imagegen.mjs 小，life 和 proactive（信纸）各带一份。
- bili/frames.py、live/phone_live.py（asr）本体看视频要用，本体带一份；life、phone 要用就各自带。
- 包的依赖写在 scripts/plugins.mjs 的 `deps` 里（只有 speech 要 ws），make-entries 写进 package.json。

兼容（别人自己装的 DSH 也要能直接装）：
- 插件包不写 `engines.dsh`、不依赖 `@deepseek-ai/*`：DSH 装插件时按这两样卡版本。入口只用 `apply(ctx)` 和卸载回调（`ctx.effect` 没有就 `ctx.on('dispose')`）。
- 本体和插件之间走 `globalThis.__dshCompanion` 登记表，不用 cordis 服务。
- 只在 Windows 上能用的（PowerShell、adb.exe、QQ 音乐、桌面、喇叭）放 pc / phone 插件里，别的系统上 setup 里直接说一声就返回，别让内核挂掉。
- `node:sqlite`（ChronoLife）只在 life 插件里用、用到时再 import：老的 Node 22 没有它，静态 import 会让整个内核起不来。
- 跑 python 用 `env.PYTHON`（内核按系统默认成 python / python3）；模型、素材只认本地，绝不自己去网上下。
- 路径一律从插件自己的目录算（`import.meta.url`），不许出现 agent-bridge、C:\Xyg 这种本机路径。
