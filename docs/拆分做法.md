# 拆一组的做法（给接手的人看）

在仓库根目录干活。目标：把 `packages/core/kernel/main.mjs`（本体内核）里某一组功能原样搬进 `packages/<插件>/module.mjs`，
做成真正独立的插件——装了才有，没装内核照常跑。先读 `docs/插件接口.md`（钩子和服务）、`docs/拆分清单.md`（每组搬哪些、兼容规矩），
再看已经搬完的 `packages/phone/module.mjs` 当样子。

## 步骤

1. 在 main.mjs 里找全这组的代码：函数、常量、状态变量、`on(...)` 登记行（大多在 buildPrompt 后面和 processTurn 后面那两段“还没搬走的”里）、
   handleEvent 里还内联着的命令、main 段末尾的 `setInterval` / 启动日志、config.mjs 里的设置项。
2. 原样搬进 `packages/<插件>/module.mjs` 的 `setup(api)` 里：
   - 内核的东西从 `api` 解构；human.mjs 的从 `api.human`；`setInterval(f, ms)` → `api.every(ms, f, 第一次ms)`；启动跑一次的 → `api.on('startup', f)`。
   - handleEvent 里内联的命令 → `api.on('message:command', async (ev, text, msg) => { ...; return true })`（没匹配返回 false）。
     注意原来的位置：在“对方开口”（state 更新）之前的放 message:command，在那之后的放 message:turn。
   - config.mjs 里这组的设置挪进插件导出的 `settings(env, parseList)`（返回设置对象），setup 里 `Object.assign(cfg, settings(env, api.parseList))`，默认值、变量名一字不改；
     功能页上这组的行写进导出的 `features(cfg, ctx)`（见插件接口.md 的“功能页”）。
   - 别的插件要用的东西 → `api.provide('名字', {...})`；要用别人的 → `api.use('名字')?.xxx`，没有就跳过或用原来没开这功能时的行为。
   - 内核里别的地方还在调这组函数的，改成钩子或 `use(...)`（内核里的 `use`/`collect`/`emit` 是现成的）。搬完 main.mjs 里不能再有这组的函数名。
   - 这组专用的脚本、python、素材目录 `git mv` 到 `packages/<插件>/` 下，路径改成从插件目录算（`path.dirname(fileURLToPath(import.meta.url))`），
     数据目录用 `api.DATA_DIR` / 环境变量 `BRIDGE_DATA`；本体也要用的就别搬（或者本体留一份）。
   - 模型要用的命令行工具，在 `api.on('agents', () => '...')` 里写用法，路径写绝对路径（见手机插件）。
3. 改 test/ 里引用的路径（import 和 spawn 的脚本路径）。
4. 跑 `node scripts/test-all.mjs`（6~7 分钟），必须全部通过；再跑 `COMPANION_ONLY=none node test/e2e.mjs`（只有本体）也要通过。
   有测试本来就测这组功能、本体单独跑时自然不该有的，不算失败；但别为了过测试改测试的判断。

## 规矩

- 行为一点不改：提示词的字、日志的字、默认值、先后顺序都照旧（背景块 order 见插件接口.md）。
- 只在 Windows 能用的（PowerShell、exe）：在别的系统上 setup 里 log 一句就 return。
- 不联网下载任何东西（模型、包都不行）；不碰仓库外面那个正在跑的老机器人的目录（主会话会说在哪）；不 git commit（交给主会话）。
- python 改文件用 `open(..., newline='')`，别把换行变成 CRLF。注释用中文，跟周围代码一个风格，大白话。
- 不往代码、注释、测试里写真实的人名、QQ 号、本机路径。
