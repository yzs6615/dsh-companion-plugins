# 插件接口

本体（`packages/core`）跑一个内核进程（`packages/core/kernel/main.mjs`）：连 QQ、收消息、拼提示词、调模型、发回复。
别的插件各自带一个 `module.mjs`，内核启动时按装了哪些插件挨个 `import`，调它的默认导出：

```js
// packages/<插件>/module.mjs
// 自己的设置：从环境变量读，默认值只写在这里（别的插件没装时 cfg.xxx 是 undefined，当“关”处理）。
// 单独导出，功能页不跑 setup 也能拿到同样的值（见下面“功能页”）
export function settings(env, parseList) {
  return { voice: (env.VOICE || 'false') === 'true', voiceMaxDay: Number(env.VOICE_MAX_DAY ?? 20) };
}

export default function setup(api, options) {
  const { cfg, env, log, state, saveState, reply, say, runAgent } = api;
  // 1. 设置挂到 cfg 上
  Object.assign(cfg, settings(env, api.parseList));
  // 2. 登记钩子、服务、定时任务
  api.on('prompt:context', (t) => (cfg.voice ? '\n\n---\n……' : ''), 30);
  api.provide('voice', { allowed, send });
  api.every(60_000, checkSomething, 20_000);
}

// 功能页上的行（可选）
export function features(cfg, { on }) {
  return { groups: [['说话的样子', [['发语音', on(cfg.voice), `一天最多 ${cfg.voiceMaxDay} 条`, '它觉得这句适合说出来就发语音……']]]] };
}
```

插件之间不互相 `import`。要用别的插件的东西走 `api.use('服务名')`，没装就是 `undefined`，要能照常跑（跳过那一段）。

## api 上有什么

| 名字 | 是什么 |
| --- | --- |
| `cfg` `env` `parseList` | 设置（本体的 + 各插件自己挂上的）、环境变量、逗号列表解析 |
| `human` | `kernel/human.mjs` 整个模块（dayKey、nowDesc、selfState、familiarity、extractXxx……） |
| `ROOT` `DATA_DIR` | 内核目录、数据目录（插件自己的数据放 `DATA_DIR` 下） |
| `log` `readJson` `pick` `sleep` `pace` | 日志、读 JSON、随机挑一个、等一会、打字节奏开关（0 = 测试里不等） |
| `state` `saveState` `userState(qq)` `closeness(st)` | state.json 和每个人的状态 |
| `sessions` `saveSessions` | 每个聊天的模型会话 |
| `persona()` `memoryFile` `readMemory` `appendMemory` | 人设、短期记忆 |
| `diaryToday()` `addDiary(text, shared)` | “今天干过啥” |
| `online()` `selfId()` | 连着 QQ 没有、机器人自己的 QQ 号 |
| `sendRaw` `sendMsg` `sendPrivate` `reply` `say` `showTyping` | 发消息（`say` 会处理回复里的标记，见下） |
| `recordGroup` `segments` `textOf` `senderName` | 群聊近况、消息段工具 |
| `groupContext(群号, 不要的消息id, 条数)` `mentions(segs, qq)` `quotesMe(segs)` `activeChats` `batches` | 读群聊近况、有没有 @ 某人、是不是引用了它自己的话、正在回的聊天（Set，插嘴时占一个 `chime:群号`）、正在攒连发的聊天（Map，chatKey → 攒着的几条） |
| `owner()` | 主人的 QQ（PC_OWNER，没设就是 PROACTIVE_QQ 第一个；都没设是空字符串）：写信、明信片、作息被带偏、电脑上的她、发说说、喇叭、放歌、发图、画画都认这一个 |
| `isOwnerChat(ev)` | 是不是主人私聊（不是群、有主人、发消息的就是主人）。权限分级都认它：只有主人私聊才用 DSH_PERMISSION_MODE，别人私聊、群里只读；音乐控制、发图、画画也只在这时办 |
| `runAgent(prompt, sessionId, opts)` `runQueued` | 调模型（`opts.permissionMode: 'read-only'` 只读）。不要工具的调用（主动消息、提炼事实、学说话总结……）都传只读。超时 / 出错时整棵进程树（taskkill /T /F）一起结束 |
| `runPyJson` `downloadTo` `saveImages` `humanize` `humanBubbles` | 跑 python 拿 JSON、下载、存图、去 AI 腔、拆气泡 |
| `myState(chatKey)` `lifeBlock(qq)` | 现在的心情精力（本体按时段算；开着 ChronoLife 跟着它（`use('life')?.state()`）；装了 mood 会在 `state:mood` 里换成有来由的心情）、提示词里的【此刻】那段 |
| `quiet()` | 现在该不该安静（睡觉时段、QUIET_HOURS、ChronoLife 休息）：主动出声、发东西前先看。睡觉时段装了 mood 就问它（会被带偏），没装按 SLEEP_START~SLEEP_END |
| `moodChanged(mood, reason, chatKey)` | 模型写的 [心情:词\|为啥] 抠出来后交给它：先过 `mood:changed`（life 让 ChronoLife 记一笔），再给 `use('mood')?.setEmotion`。聊天回复本体自己调，自己找事做（life）也调 |
| `activeRuns()` `lastAnswer` `markRead(ev)` | 正在回的轮数（ChronoLife 主动分享要等没人在聊）、每个聊天上一句回了啥（Map，chatKey → `{ text, at }`，“好的”是不是在回答问题；电台录完也记一笔）、私聊标已读（点电台时） |
| `on(钩子, fn, order)` | 登记钩子，order 小的先 |
| `provide(名字, 实现)` `use(名字)` | 提供 / 取用服务 |
| `every(ms, fn, 第一次ms)` | 定时任务（内核连上 QQ 后开始） |
| `collect` `emit` `first` `pipe` | 插件自己也能开钩子给别的插件挂 |

## 钩子

| 钩子 | 怎么调 | 参数 → 返回 | 在哪 |
| --- | --- | --- | --- |
| `startup` | emit | () | 加载完全部插件、连 QQ 之前 |
| `prompt:state` | collect | (qq, chatKey) → 字符串 | 【此刻】那段里，在心情、熟悉度后面 |
| `prompt:context` | collect | (turn) → 字符串 | 背景块，会过 `context:filter` |
| `prompt:after` | collect | (turn) → 字符串 | 背景块后面（不过滤） |
| `prompt:hint` | collect | (turn) → 字符串 | 提示词最末尾 |
| `context:filter` | pipe | (text, chatKey) → 新 text | 背景块、短期记忆、长期事实读出来时过一遍（删掉的记忆在这里拦） |
| `message:command` | first | (ev, text, msg) → 真值 = 处理掉了 | 白名单之后、进模型之前（斜杠命令、选人、ChronoLife 记一笔收到的消息……） |
| `message:incoming` | emit | (ev, msg) | 每条放行的消息（偷表情包、记作息……） |
| `turn:after` | emit | (turn) | 回复发完之后（提炼事实、记日记流水、等你回……） |
| `notice` | first | (data) → 真值 = 处理掉了 | QQ 的通知事件（戳一戳……） |
| `say:extract` | pipe | ({ text, tags }) → 同样形状 | `say()` 发之前，从模型输出里抠掉自己的标记，记进 tags（人设里教它写的 [唱歌] [语音] [表情:xx] 和 [心情:xx] 由本体抠，见下） |
| `natural:act` | 依次问（本体自己的循环） | (ev, act, ctx) → 真值 = 接手了 | 回完这一轮（`turn:after` 32）把抠出来的大白话标记挨个交出去：`act` 是 `{ kind, body }`，`ctx` 是 `{ chatKey, isGroup, turn, pics }`。钩子抛错本体补一句“诶 刚答应你的那个没弄成”；没人接手补一句“诶 这个我现在弄不了”（见下面“大白话办事”） |
| `natural:hint` | collect | (turn) → 字符串 | 提示词末尾“下面这些事对方用大白话说就能办”那段里各插件教的行，每行 `'\n- …'` 开头；功能关着、不是主人、在群里不该办的就别教（返回 ''） |
| `natural:note` | collect | (act, turn) → 字符串 | 记进短期记忆时补的“（答应了明天 08:00 提醒对方：起床）”这种，按标记的先后一个个问 |
| `mood:changed` | pipe | (false, mood, reason, chatKey) → true = 这个心情不算了 | 本体 `moodChanged` 里、交给 mood 插件之前：life 让 ChronoLife 记一笔（“没回”“冷落”这种它自己管，返回 true，mood 插件也就不管了） |
| `shutdown` | collect（同步） | () | 内核收到 SIGINT / SIGTERM、退出之前（life 关 ChronoLife 的数据库） |
| `say:send` | first | (target, text, tags, opts) → 真值 = 已经发了 | 发正文：语音插件在这里接手，没人接就打字 |
| `say:after` | emit | (target, text, tags, opts) | 正文发完：唱歌、表情包…… |
| `agents` | collect | () → Markdown 段落 | 启动时拼成 `<COMPANION_HOME>/AGENTS.md`（模型的工作目录在那，它会读）：插件带的命令行工具怎么用、用的时候的规矩，路径写绝对路径（从插件目录、数据目录算，不写本机路径）。本体的“几条规矩”排最前面（order 0） |
| `help` | collect | (ev) → 字符串 | `/help` 里“直接跟我说就行，比如：”下面的例子，每行 `'\n· “例子”'` 开头；按发消息的人、功能开没开给（不是主人、在群里用不了的别列） |
| `message:seen` | emit | (ev, segs) | 每条消息一进来（白名单之前，别在这里回话） |
| `message:group` | first | (ev, segs) → `{ wokeWord }` 或 null | 群消息理不理；返回 null = 不理（没装群聊插件就一概不理） |
| `message:raw` | first | (ev, segs) → 真值 = 接手了 | 白名单之后、还没取文字之前（合并转发……） |
| `message:user` | emit | (ev, st, msg) | 对方开口了、在小命令之前（被冷落的小情绪……）。这时 `st.ignored`（主动找了几次没回）还是清零前的数，钩子跑完内核才清零、saveState |
| `message:turn` | first | (ev, text, msg) → 真值 = 接手了 | 小命令之前、进模型之前（点电台……） |
| `turn:start` | emit | (turn) | 这一轮开始（`turn.running()` 这一轮还没结束） |
| `prompt:images` | collect | (turn) → 字符串 | 对方发了图时，图片说明后面补的话 |
| `turn:answer` | pipe | (answer, turn) → 新 answer | 模型回完、发之前，抠掉给插件的标记，记进 `turn.tags` |
| `turn:record` | emit | (turn) | 记进短期记忆的同时、发回复之前（记日记流水……） |
| `turn:spoken` | collect | (sayTags, turn) → 字符串 | 记进短期记忆时补的“（唱了一段……）” |
| `prompt:context-late` | collect | (turn) → 字符串 | 短期记忆后面的背景块（群聊近况 170、被冷落 180（mood）），也过 `context:filter` |
| `rhythm:times` | emit | (per) | memory 插件按 bridge.log 算完每个人的作息、saveState 之前：`per` 是 Map（QQ → 这个人每条消息的时间戳），mood 插件的作息被带偏在这里挪睡觉时段（没装 memory 或 RHYTHM=false 就不挪） |
| `state:mood` | pipe | (s, chatKey) → s | `myState()` 算完按时段的心情之后（开着 ChronoLife 就不走这里）：mood 插件换成被事情影响的心情、熬夜后犯困（`s` 是 `{ part, mood, energy, energyDesc, reason? }`） |

注意：`emit` / `first` 会等钩子返回的 Promise。要在后台一直跑的（比如盯着手机直到这一轮结束），在钩子里启动后别 `return` 它：
`api.on('turn:start', (t) => { watch(t).catch(() => {}); })`。

`turn` 对象：`{ ev, text, isGroup, chatKey, qq, who, excludeIds }`；`turn:after` 里另有 `raw`（模型原始输出）和 `spoken`（发出去的字）。

`say:extract` 的 order：电台 10（life）、心情 20、唱歌 30、语音 40、表情包 50。[心情:词|为啥] 也由本体抠（没装 mood 也不会原样发出去）；`say()` 里抠出来的心情不算数，
跟原来一样只有聊天回复（`turn:answer` 20，本体抠完交给 `moodChanged`：先过 `mood:changed`（开着 ChronoLife 让它记一笔，life），再 `use('mood')?.setEmotion`）和自己找事做（life，也走 `api.moodChanged`）的心情才算。唱歌、语音、表情包这三个标记是人设（persona）里教它写的，
本体自己抠掉、记成 `tags.sing`（null = 没写，'' = 随便唱一首）、`tags.voice` / `tags.tone`、`tags.moods`，没装 speech 插件也不会原样发出去；
speech 插件在 `say:send`（发语音）和 `say:after`（唱歌 10、表情包 20）里按这些 tags 发。`say:after` 里群聊插件记“跟谁说上话了”排在 1000（最后）。
`say()` 的 `opts.casual`（闲聊回复，记一笔发没发表情包）、`opts.autoMood`（没点表情时按梗补一张的概率）是给 speech 插件看的。

`turn:after` 的 order（跟原来一个钩子里的先后一致）：ChronoLife 记一笔发出去的话和现场照 10（life）、放歌 20（pc）、收礼物和明信片 30（life，给了攒着的明信片记 `turn.gaveCard`）、
大白话办事 32（本体，挨个交给 `natural:act`）、记下“问了没回” 35（proactive）、点电台 40（life）、提炼事实 90（memory）、清掉这一轮的小情绪 10000（mood，原来在 turn:after 全跑完之后）。
答应了没办成的都补一句人设口吻的话：照片没拼成（life 10）、群里 / 没开放歌（pc 20）、礼物没摆好（life 30）。

`turn:answer` 的 order：收表情 10（speech）、心情 20（本体）、电台 30（life）、照片 40（life）、放歌 50（pc）、收礼物 60（life）、大白话标记 65（本体）、凌晨还在聊记一笔熬夜 70（mood）。

`prompt:hint` 的 order：教它写 [心情] 10（mood）、表情包太少时提醒 15（speech）、照片 20（life）、礼物 30（life）、放歌和音乐控制 40（pc）、大白话办事 50（本体，里面拼各插件的 `natural:hint`）、每轮的规矩 60（本体：只用自己的声音、QQ 资料系统管、别自己连 OneBot；不是主人私聊再说手机、屏幕、文件、放歌只听主人的）。

`message:command` 的 order：ChronoLife 记一笔收到的消息和 /生活 是 0（life，原来在所有命令前面；不是 /生活 就返回 false）；各插件的命令默认 100（/明信片 也是）；memory 的 /城市 /生日 /日记 是 110（原来排在学说话选人、/别学了 后面）。

`message:turn`：点电台（life，说了“开台”“来一期”、投稿等稿子时直接录，不进普通聊天）。`turn:spoken` 的 order：唱歌 10（speech）、放歌 20（pc）、收礼物 30（life）、大白话答应了啥 40（本体，问 `natural:note`）。

## 大白话办事（natural:act / natural:hint / natural:note）

以前要发斜杠命令的事，现在直接跟她说：她在回复里写个标记，**本体在 `turn:answer` 65 把下面这些标记全抠掉**（不管管它的插件装没装，都不会原样发出去；抠完什么都不剩就发“行”），
记进 `turn.tags.natural`（`[{ kind, body }]`，同样的去重），回完这句在 `turn:after` 32 挨个交给 `natural:act`。斜杠命令照样能用，跟大白话走同一个函数（`startLetter(ev, natural)` 这种，natural 为真时不再说“等我写写”）。

| 标记 | 谁办 | 条件 |
| --- | --- | --- |
| `[提醒:分钟数\|内容]` `[提醒:年-月-日 时:分\|内容]` | 本体 | 只能设一次性的；1 秒 ~ 一年以内，看不懂 / 已经过了补一句 |
| `[发图:完整路径]` | 本体 | 只主人私聊；只发数据目录下 `shots` `live` `scene` `bili/frames` `letters` `postcards` `drawings`（另加 SCENE_DIR）里真有的图片，`..` 和链接越界的不发，10MB 以内，一轮最多 3 张 |
| `[城市:…]` `[生日:月-日]` `[看日记]` | memory | 城市要查得到天气；生日看不懂补一句；没写过日记补一句 |
| `[写信]` | proactive | 只私聊、开着 LETTER；正在写补“在写了 别催” |
| `[寄明信片]` `[记住:…]` `[忘掉:几个字]` `[更正:几个字\|改成啥]` `[生活:主动 开/关\|暂停\|恢复\|停用\|启用\|兴趣 x n]` `[画:描述]` | life | 明信片只私聊，这轮给过攒着的就不再寄；记住 / 忘掉 / 更正 / 开关要开着 ChronoLife，走 `/生活` 同一个入口（开关只听主人的），忘掉 / 更正按内容找（`LifeAdapter.findMemory`）；画画只主人私聊、要 DASHSCOPE_API_KEY、一天 DRAW_MAX_DAY 张 |
| `[发说说]` | profile | 只主人私聊、开着 QZONE |
| `[学说话:序号或名字]` `[别学了]` | speech | 学说话要有 15 分钟内转发、等着选人的聊天记录 |
| `[喇叭:要说的话]` `[音乐:暂停\|继续\|下一首\|上一首\|大声\|小声]` | pc | 只主人私聊；喇叭要开 SPEAKER 和语音、夜里不出声、一天 SPEAKER_ASK_MAX_DAY 句；音乐跟着 PLAY_MUSIC |

- 写信、寄明信片、发说说、画画要好一会儿：`natural:act` 里启动后别 `await`（不占着这个聊天），直接返回 true。
- 办成了不另外发“已设置”“已记录”（她自己回过一句了）；办不成一定补一句人设口吻的话，并记日志（“大白话xx：没办（为啥）”）。
- 教她写哪些：提示词末尾 `prompt:hint` 50 那段，本体先写提醒的几行（含“只能设一次”和这个人还没到点的提醒），再拼 `natural:hint`：
  城市 / 生日 / 看日记 20（memory）、写信 30（proactive）、明信片 40（life）、说说 50（profile）、喇叭 60（pc）、发图 70（本体）、画画 80（life）、学说话 90（speech）、ChronoLife 100（life）。
  功能没开、不是主人、在群里的不教；对方说了却办不了的（喇叭没开、不是主人让画画），那一行直接告诉她为啥、让她跟对方说。
- `/help` 的例子按这个先后（`help` 钩子的 order）：提醒 10（本体）、城市 20、生日 25（memory）、唱歌和语音 30（speech）、喇叭 40（pc）、发语音 50（本体）、放歌 60（pc）、画画 70、电台 80（life）、
  日记 90（memory）、写信 100（proactive）、明信片 110（life）、说说 120（profile）、学说话 130（speech）、ChronoLife 140（life）。

## 权限分级和每轮的规矩（本体）

- 主人统一按 `api.owner()`（PC_OWNER，没填就是 PROACTIVE_QQ 第一个）。只有 `isOwnerChat(ev)` 时聊天用 DSH_PERMISSION_MODE；别人私聊、群里（主人在群里也一样）`permissionMode: 'read-only'`，补话那次也一样。
- 主动消息（proactive 的 genProactive）、提炼长期事实（memory 的 extractFacts）也是只读。
- 超时、dsh 起不来：会话留着、不整轮重跑，回一句“想太久了 再说一遍”；只有 dsh 明说会话没了 / 坏了（`SESSION_GONE`：`session "…" not found`、`failed validation` 这些）才丢掉会话重开。
- 听 QQ 语音（本体，HEAR_VOICE）：`record` 段 → `get_record`（转 wav）→ 不行 `get_file` → 段里的 path / url，存 `<数据目录>/voice-in/`（留 30 个）→ `kernel/media/asr.py`（`ASR_SCRIPT` 可换，参数 `<文件> --model base`）。
  只认 `WHISPER_MODEL_DIR/base/model.bin`，没有就不听（不联网）。没听成：只有语音就回“没听清 打字吧”（不过模型），带了别的字就注一句。

`context:filter` 只有 life 挂（ChronoLife 删掉的记忆在这里拦；开着 ChronoLife 但它没起来就什么都不给），没装 life 原样返回。本体读短期记忆、memory 读长期事实和日记时每一条也过一遍；
开着 ChronoLife 但它没起来（`use('life')?.memoryOff()`）就当没有，本体也不续接旧会话。

背景块的 order（跟原来提示词里的先后一致）：
自我 10（life）、学某人 20、歌单 30、电台 40（life）、长期事实 50、日记 60、合并转发 70、在忙 80（life）、电脑 90、梦 100、旅行 110、礼物 120（这三个 life）、作息 130、好奇 140、对方的说话习惯 150、短期记忆 160（本体）、群聊近况 170（群聊插件）、被冷落 180（mood）。
`prompt:after`：对方让她记住的（`/生活 记住`，life）。

`prompt:state`（【此刻】那段）的 order：作息被带偏 10（mood）、今天是个日子和对方那边的天气 20（memory）、ChronoLife 小屋近况 30（life）。

## 功能页（settings / features 导出）

本体的 `kernel/scripts/features.mjs` 生成“功能与机制”页（`<数据目录>/features.html`，`node <本体>/kernel/scripts/features.mjs`，`--no-open` 只生成、`--out <文件>` 换地方；
`--text` 不生成网页，只在终端打印每个功能开没开和现在的设置——AGENTS.md 里让模型查“开了哪些功能”用这个，不去读 .env）。
它**不跑插件的 setup**（不连 QQ、不开定时任务、不写数据）：只 `import` 每个插件的 module.mjs，先把所有插件的 `settings(env, parseList)` 挂到 cfg 上，再挨个调 `features(cfg, ctx)`。所以：

- module.mjs（和它顶层 import 的文件）在顶层不能有副作用：连东西、开定时器、读写数据都放 setup 里。
- `settings` 只从环境变量算设置，默认值只写在这里；setup 里 `Object.assign(cfg, settings(env, api.parseList))`，内核和功能页拿到的一样。
- `features` 只读文件、不写，可以是 async（life 要 `await import('node:sqlite')`）；`cfg` 里已经有本体和所有装了的插件的设置（别的插件没装就是 undefined）。
  出错只在页头记一笔“没加载上”，别的插件照常。没导出 `features` 的插件页面上没有它的行。

装了哪些插件：内核里有 `COMPANION_MODULES` 就照它；单独跑时扫本体旁边的插件（仓库里 `packages/*/module.mjs`，装进 DSH 是 `node_modules/dsh-companion-*/module.mjs`），
`COMPANION_ONLY` 跟 bridge.mjs 一样能只挑几个（`none` = 只有本体）。没装的插件不出现在页面上。数据目录跟内核一样（BRIDGE_DATA，没有就是 `<COMPANION_HOME>/data`）。

`ctx`：`{ env, ROOT, DATA_DIR, state, readJson, esc, when, pct, on, dayKey }`——环境变量、内核目录、数据目录、state.json 的内容、读 JSON（`readJson(文件, 读不到时给的)`）、
HTML 转义、毫秒时间转“2026/10/28 21:00:00”、0.3 转“30%”、`on(条件)` → `'on'` / `'off'`、`human.mjs` 的 dayKey。

`features` 返回一个对象，下面几样都可以不给：

| 字段 | 格式 | 是什么 |
| --- | --- | --- |
| `groups` | `[[组名, [[名字, level, 现在的设置, 怎么工作, order?], ...]], ...]` | 功能表的行。level：`on` 开 / `off` 关 / `idle` 开着但现在用不上 / `warn` 注意。设置和说明是纯文字（会转义） |
| `natural` | `[[怎么说, 说明, order?], ...]` | “直接跟她说”那张表（大白话办事的例子，order 跟 `help` 钩子一样） |
| `commands` | `[[命令, 说明, order?], ...]` | “命令（在 QQ 里发）”那张表 |
| `tools` | `[[名字, HTML, order?], ...]` | “工具和文件”那张表（HTML 自己用 `ctx.esc` 转义） |
| `sections` | `[[标题, HTML], ...]` | 放在“它此刻”后面的整块（life 的“它慢慢长出来的样子”） |
| `person` | `(qq, st) => HTML` | “每个人”那张卡片里补的（memory：记得的事、说话习惯、回访待办） |
| `mood` | 字符串 | “它此刻”里显示的心情，换掉按时段的（mood：有来由的心情、熬夜后犯困） |
| `taken` | `{ 行名: [说明, 是否整个不单独发了] }` | 开着 ChronoLife 时归它管的别的插件的行（life）：那行是“开”时说明前面加上这句，第二项为真就显示成“归 ChronoLife 管” |

组按这个先后排：聊天、说话的样子、记得你、心情和作息、她自己的生活、主动找你、电脑上的她、QQ 上的样子、群聊、手机和权限（别的组名排在最后）。
一个组里几个插件都有行时按 order 排（没写是 100，一样大的按加载的先后：本体先，插件按 COMPANION_MODULES 里的先后，单独跑时按目录名）：

- 心情和作息：心情和精力 10（本体）、心情有来由 20、作息被你带偏 30、被冷落有情绪 40（mood）。
